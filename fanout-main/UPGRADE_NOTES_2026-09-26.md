# 2026-09-26 upgrade

- 国家出口上限支持 `运营商必须不同` / `允许重复` 两种模式；默认不同运营商。
- 同国不同运营商策略统一作用于手动、批量、智能编排和自动恢复路径。
- 订阅使用独立 subscription token，不再把后台登录口令直接作为订阅密钥。
- 支持一键重置订阅链接，旧链接立即失效。
- 支持订阅流量上限（GB）和到期时间，并同步到 3x-ui 客户端 `totalGB` / `expiryTime`。
- 支持一键重置指定节点及其克隆入站的全部客户端 UUID / Trojan 密码。
- 修复订阅链接在设置了 base path 时仍指向根路径的问题。
- 保留原有节点源、测活、智能编排、筑波大学/高校节点等功能。
